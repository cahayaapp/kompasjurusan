KOMPAS JURUSAN V9.6 - LAPORAN PDF RESMI

FITUR BARU
1. Peserta dapat mengunduh setiap hasil asesmen sebagai PDF profesional.
2. PDF terdiri dari 3 halaman A4:
   - Data peserta + ringkasan utama + profil RIASEC.
   - Tabel rumpun studi, jurusan, dan mapel pilihan TKA yang perlu diperdalam.
   - Penjabaran kekuatan akademik, gaya kerja, nilai hidup, dan saran tindak lanjut.
3. Header laporan menggunakan identitas Kompas Jurusan dan nomor laporan unik.
4. Mapel wajib TKA selalu ditampilkan: Bahasa Indonesia, Bahasa Inggris, Matematika.
5. Mapel pilihan TKA dihitung sesuai rumpun/jurusan yang direkomendasikan.
6. Admin memiliki menu baru "Hasil Tes" untuk mengunduh laporan PDF semua peserta.
7. Admin juga bisa mengunduh PDF dari daftar peserta dan hasil terbaru di dashboard.

CATATAN
- PDF dibuat langsung di browser tanpa library CDN tambahan, sehingga tidak bergantung pada layanan pihak ketiga.
- Firebase Rules tidak perlu diubah untuk fitur PDF.
- Data hasil lama tetap dapat diunduh; rekomendasi TKA akan dihitung dari mapping yang tersedia.
