1. Struktur rumpun tetap seperti konsep lama.
2. Pada hasil rekomendasi, setiap rumpun mempunyai kolom "Jurusan Umum" dan "Ilmu Keislaman" secara berdampingan.
3. Ilmu Keislaman tidak menjadi rumpun baru; program studi ditempatkan sesuai bidang ilmunya.
4. PDF laporan resmi: tabel rekomendasi memuat Rumpun Studi, Jurusan Umum, Ilmu Keislaman, persentase kecocokan, dan mapel pilihan TKA.
5. Penjelasan tentang asesmen dipindahkan ke halaman 4-5 PDF.
   - Halaman 4: Tentang Kompas Jurusan, pentingnya asesmen, dan empat dimensi.
   - Halaman 5: Penjelasan RIASEC dan panduan membaca hasil.
6. Halaman 1-3 difokuskan pada hasil individual, rekomendasi studi/TKA, dan tindak lanjut.
7. Firebase Rules tidak berubah.
